# markdown_widget支持自定义选择模式需求说明
## 需求背景
当前的`markdown_widget`的工程是一个在Flutter平台用于渲染Markdown内容的控件。目前已经支持对markdown的选择和复制的能力，通过初始化`MarkdownWidget`的时候参数`selectable`设置为`true`.并且默认为`true`。markdown内容的选择和复制能力的底层是基于Flutter的SDK中的`SelectionArea`实现，而`markdown_widget`对外暴露的内容选择和复制能力也比较受限，用户长按内容区域弹出的功能菜单浮窗的样式也不支持定制。在实际的业务场景中，我们需要一种更加灵活的内容选择范围，并且能够支持自定义弹出功能菜单的样式。

## 需求内容
1. 如果未开启自定义选择模式，并且初始化`MarkdownWidget`的时候参数`selectable`设置为`true`，长按`MarkdownWidget`的内容区域后续逻辑保持现有的逻辑不变。
2. 如果开启了自定义选择模式，当用户长按`MarkdownWidget`的内容区域，此时暂时先不选中文字，而是会先在用户手按住的位置上方弹出自定义功能菜单浮窗，样式支持自定义，菜单中默认包含`选取文字`功能项，支持自定义其他功能菜单扩展。当用户点击`选取文字`菜单后，此时的文字选中的范围默认为当前点击处的markdown元素的全部内容，并在选中区域上方弹出包含有`复制`功能菜单浮窗，当用户这个时候点击`复制`菜单才是真正复制内容。
3. 关于第2条中的提到的对点击处的markdown元素的全部内容进一步说明，如果点击的位置对应的markdown的元素标题，比如`一级标题`，则此时将整个标题渲染的区域全部选中，如果选中的区域是markdown的元素是正文部分，则将选中全部正文部分。如果是列表，则选中的是当前列表对应的列表项。如果是引用，代码块这类，点击选取文字会选中该区块内的全部文字。其他markdown元素以此类推。当选中了当前点击处的markdown元素的内容之后，用户还是可以拖动选中区域开始或者结束位置的光标调整选择范围。

## 需求目标
根据我前面的描述，结合对当前`markdown_widget`工程源码的深入理解，完成对`MarkdownWidget`支持自定义选择模式方案的设计和实现。并在项目的`example`目录下给出该模式的使用范例代码。其中对Flutter的版本要求为`3.27.4`.
