## 一、需求背景

### 1.1 现状分析

当前的 `markdown_widget` 是一个在 Flutter 平台用于渲染 Markdown 内容的控件。目前已经支持对 markdown 的选择和复制能力，通过初始化 `MarkdownWidget` 时设置参数 `selectable` 为 `true` 开启（默认为 `true`）。

**现有实现的局限性**：
- Markdown 内容的选择和复制能力基于 Flutter SDK 的 `SelectionArea` 实现
- 用户长按内容区域弹出的功能菜单浮窗样式**不支持定制**
- 菜单项**无法扩展**，只能使用系统默认的复制功能
- 选择粒度为全局文本，**无法按 Markdown 语义结构**（标题、段落、列表项等）精准选择

### 1.2 业务需求

在实际的业务场景中，我们需要：
1. **更灵活的选择粒度**：按 Markdown 块级元素进行选择
2. **可定制的菜单样式**：符合应用品牌风格的菜单外观
3. **可扩展的菜单功能**：支持收藏、分享、翻译、AI 摘要等自定义操作
4. **更友好的交互流程**：先显示功能菜单，再选择文字

### 1.3 目标用户

- **应用开发者**：需要为最终用户提供定制化的 Markdown 阅读体验
- **最终用户**：期望更精准的内容选择和更丰富的操作选项

## 二、功能概述

### 2.1 核心能力

本需求将为 `MarkdownWidget` 新增**自定义选择模式**，具备以下核心能力：

| 能力 | 说明 |
|------|------|
| **全局开关** | 通过配置参数开启/关闭自定义选择模式 |
| **自定义菜单** | 完全自定义菜单样式（颜色、图标、布局、动画） |
| **元素级选择** | 按 Markdown 块级元素（标题、段落、列表项等）进行精准选择 |
| **菜单扩展** | 支持自定义菜单项，并提供元素上下文信息 |
| **向后兼容** | 未开启时保持现有 `SelectionArea` 行为不变 |

### 2.2 交互流程

```
用户操作               系统响应
   │
   ├─ 长按内容         → 显示自定义菜单（包含"选取文字"、"复制"、"收藏"、"分享"及扩展项）
   │                     （此时暂不选中文字）
   │
   ├─ 点击"选取文字"   → 选中当前 Markdown 元素的全部内容
   │                     显示选择句柄
   │                     显示"复制"菜单
   │
   ├─ 拖动选择句柄     → 调整选择范围
   │                     菜单隐藏（拖动时）
   │                     菜单重新出现（拖动结束后）
   │
   ├─ 点击"复制"       → 复制选中内容到剪贴板
   │                     清除选择状态
   │
   ├─ 点击"收藏"       → 收藏整个 Markdown 文档
   │                     菜单消失
   │
   ├─ 点击"分享"       → 分享整个 Markdown 文档
   │                     菜单消失
   │
   ├─ 点击扩展菜单项   → 执行自定义操作（带元素上下文）
   │                     菜单消失
   │
   ├─ 滚动页面（选中状态）→ 菜单消失
   │                     选择区域和句柄保留
   │                     停止滚动后菜单重新出现
   │
   └─ 点击菜单外       → 菜单消失
                         （如有选择）清除选择状态
```

## 三、详细需求说明

### 3.1 全局开关与配置

#### 3.1.1 API 接口定义

```dart
MarkdownWidget(
  data: markdownData,
  // 现有参数，保持兼容
  selectable: true,
  
  // 新增参数：开启自定义选择模式
  enableCustomSelection: true,
  
  // 新增参数：自定义选择配置（可选）
  customSelectionConfig: CustomSelectionConfig(
    menuStyle: MenuStyle(...),           // 菜单样式配置
    animationConfig: MenuAnimationConfig(...), // 动画配置
    extension: MenuExtension(...),       // 菜单扩展配置
    hiddenBuiltInItems: {...},          // 隐藏的内置菜单项
  ),
)
```

#### 3.1.2 配置对象说明

**CustomSelectionConfig**

```dart
class CustomSelectionConfig {
  final bool enabled;                      // 是否启用（默认 false）
  final MenuStyle menuStyle;               // 菜单样式
  final MenuAnimationConfig animationConfig; // 动画配置
  final MenuExtension extension;           // 扩展菜单项
  final Set<BuiltInMenuItem> hiddenBuiltInItems; // 隐藏的内置项
}
```

**MenuStyle**

```dart
class MenuStyle {
  // 容器样式
  final Color? backgroundColor;
  final double? elevation;
  final BorderRadius? borderRadius;
  final BoxBorder? border;
  final EdgeInsets? padding;
  
  // 文字样式
  final TextStyle? textStyle;
  final Color? iconColor;
  final double? iconSize;
  
  // 布局样式
  final MenuLayout layout;                 // horizontal/vertical/grid
  final double? itemSpacing;
  final double? dividerThickness;
  final Color? dividerColor;
}
```

**MenuAnimationConfig**

```dart
class MenuAnimationConfig {
  final Duration enterDuration;            // 进场动画时长
  final Duration exitDuration;             // 退场动画时长
  final Curve enterCurve;                  // 进场动画曲线
  final Curve exitCurve;                   // 退场动画曲线
  final MenuAnimationType type;            // 动画类型
}

enum MenuAnimationType {
  fade,           // 淡入淡出
  scale,          // 缩放
  fadeScale,      // 淡入+缩放
  slideFromTop,   // 从顶部滑入
  slideFromBottom,
  slideFromLeft,
  slideFromRight,
}
```

**MenuExtension**

```dart
class MenuExtension {
  final List<CustomMenuItem> items;        // 自定义菜单项列表
  final MenuInsertPosition position;       // 插入位置
}

enum MenuInsertPosition {
  afterBuiltIn,      // 所有内置项之后
  afterSelectText,   // "选取文字"之后
  afterCopy,         // "复制"之后
  replaceAll,        // 完全替换菜单
}
```

**CustomMenuItem**

```dart
class CustomMenuItem {
  final String label;                      // 显示标签
  final IconData? icon;                    // 图标
  final VoidCallback? onTap;               // 简单回调
  final ElementContextAction? onContextTap; // 带上下文的回调
  final bool enabled;                      // 是否启用
  
  // 样式覆盖
  final Color? textColor;
  final Color? iconColor;
  final Color? backgroundColor;
}

// 上下文操作回调
typedef ElementContextAction = void Function(ElementContext context);
```

**ElementContext**

```dart
class ElementContext {
  final int index;                         // 元素在 ListView 中的索引
  final String elementType;                // 元素类型（heading/paragraph/codeBlock等）
  final String plainText;                  // 元素纯文本内容
  final String fullMarkdown;               // 整个 Markdown 文档
  final TextSelection? selection;          // 当前选择范围
  final String? selectedText;              // 选中的文本
}
```

### 3.2 行为规则

#### 3.2.1 模式切换规则

| `selectable` | `enableCustomSelection` | 行为 |
|-------------|------------------------|------|
| `false` | 任意 | 禁用所有选择功能 |
| `true` | `false` | 使用默认 `SelectionArea` 行为 |
| `true` | `true` | 启用自定义选择模式 |

#### 3.2.2 元素选择规则

**基本规则**：长按某个 Markdown 元素并点击"选取文字"后，选中该元素的全部内容。

| Markdown 元素 | 选择范围 | 说明 |
|--------------|---------|------|
| **标题** (h1-h6) | 整个标题文本 | 包括标题内的所有文字，不包括分隔线 |
| **段落** (p) | 整个段落 | 当前段落的所有文字 |
| **列表项** (li) | 单个列表项 | 仅选中该列表项，不包含其他列表项 |
| **引用** (blockquote) | 引用块的全部文字 | 包括引用内的所有段落和列表 |
| **代码块** (pre) | 代码块的全部代码 | 保留原始换行和缩进 |
| **表格单元格** | 单个单元格内容 | 用户可拖动句柄扩展到其他单元格 |
| **链接** (a) | 链接的显示文本 | 不包含 URL，点击链接仍触发导航 |
| **嵌套元素** | 最内层块级元素 | 如引用内的列表项，选中列表项而非整个引用 |
| **行内元素** (code/bold/italic) | 所在段落 | 行内元素不单独作为选中单元 |
| **图片** (img) | 不触发选择菜单 | 图片无文本内容 |
| **水平线** (hr) | 不触发选择菜单 | 非内容元素 |

#### 3.2.3 嵌套元素选择规则

当 Markdown 存在嵌套结构时，遵循**最内层块级元素**原则：

**示例 1：引用内的列表**
```markdown
> - Item 1
> - Item 2
```
- 长按 Item 1 → 仅选中 "Item 1"，不选中整个引用块

**示例 2：列表项内的代码块**
```markdown
- List item text
  
  ```python
  code here
  ```
```
- 长按代码块 → 仅选中代码块，不选中整个列表项

**示例 3：多层嵌套引用**
```markdown
> Level 1
> > Level 2
> > > Level 3
```
- 长按 Level 3 → 仅选中 Level 3 段落，不选中外层引用

#### 3.2.4 表格选择规则

**单元格级选中**：
- 长按表格单元格 → 选中该单元格内容
- 拖动选择句柄 → 可扩展到相邻单元格
- 复制时 → 仅复制文本内容，不包含表格格式

### 3.3 菜单行为

#### 3.3.1 初始菜单（长按后显示）

**内置菜单项**：
- "选取文字"：触发元素选中
- "复制"：复制整个元素内容到剪贴板
- "收藏"：收藏整个 Markdown 文档（需业务侧实现回调）
- "分享"：分享整个 Markdown 文档（需业务侧实现回调）

**扩展菜单项**：
- 通过 `MenuExtension.items` 添加自定义项
- 可访问 `ElementContext` 获取元素信息

#### 3.3.2 复制菜单（选中后显示）

**内置菜单项**：
- "复制"：复制选中的文本到剪贴板

**扩展菜单项**：
- 通过 `MenuExtension.items` 添加自定义项
- 可访问 `ElementContext.selectedText` 获取选中文本

#### 3.3.3 菜单定位规则

**基本规则**：菜单默认显示在触摸/选择区域的上方。

**边界处理**：
- 靠近屏幕顶部 → 菜单显示在下方
- 靠近屏幕左边缘 → 菜单向右偏移
- 靠近屏幕右边缘 → 菜单向左偏移
- 键盘弹出 → 菜单位置自动调整

#### 3.3.4 菜单生命周期

| 场景 | 菜单行为 |
|------|---------|
| 点击菜单项 | 执行操作后菜单消失 |
| 点击菜单外区域 | 菜单消失，清除选择状态 |
| 拖动选择句柄 | 菜单隐藏，拖动结束后重新出现 |
| 滚动页面 | 菜单消失，选择区域和句柄保留，停止滚动后菜单重新出现 |
| 设备旋转 | 菜单位置重新计算 |
| 另一处长按 | 旧菜单消失，新菜单出现 |

### 3.4 手势交互

#### 3.4.1 长按手势

- **触发条件**：长按 Markdown 内容区域超过 500ms
- **触发对象**：可选中的块级元素（排除图片、水平线）
- **手势冲突处理**：使用 `HitTestBehavior.translucent`，不阻止滚动

#### 3.4.2 点击手势

- **点击链接**：触发导航（不触发选择）
- **点击复选框**：切换勾选状态（不触发选择）
- **点击选中区域内**：重新显示菜单
- **点击选中区域外**：清除选择和菜单

#### 3.4.3 拖动手势

- **拖动选择句柄**：实时调整选择范围
- **拖动时**：菜单隐藏
- **拖动结束**：菜单在新选择位置重新出现

#### 3.4.4 滚动手势

- **垂直滚动**：正常滚动，不影响长按检测
- **选中状态下滚动**：菜单消失，选择区域和句柄保留
- **停止滚动后**：菜单在选择区域上方重新出现

## 四、非功能性需求

### 4.1 性能要求

- **渲染性能**：长文档（500+ 元素）下，包裹 CustomSelectableWrapper 不应导致明显卡顿
- **菜单响应**：长按到菜单显示延迟 < 100ms
- **动画流畅度**：菜单动画保持 60fps

### 4.2 平台支持

| 平台 | 支持情况 |
|------|---------|
| **移动端**（Android/iOS） | 完全支持 |
| **桌面端**（Windows/macOS/Linux） | 支持，右键等效于长按 |
| **Web** | 支持，但浏览器原生菜单可能冲突 |

### 4.3 兼容性

- **Flutter 版本**：要求 `3.27.4`
- **向后兼容**：`enableCustomSelection: false` 时行为与当前版本完全一致
- **MarkdownBlock**：本需求仅针对 `MarkdownWidget`，`MarkdownBlock` 不在范围内

### 4.4 无障碍（Accessibility）

- 菜单项支持语义标注（`Semantics`）
- 选中状态通知屏幕阅读器
- 支持键盘导航（桌面端）

## 五、使用示例

### 5.1 基础用法

```dart
MarkdownWidget(
  data: '# 标题\n\n这是一段文字',
  enableCustomSelection: true,
)
```

### 5.2 自定义菜单样式

```dart
MarkdownWidget(
  data: markdownData,
  enableCustomSelection: true,
  customSelectionConfig: CustomSelectionConfig(
    menuStyle: MenuStyle(
      backgroundColor: Colors.black87,
      textStyle: TextStyle(color: Colors.white, fontSize: 14),
      iconColor: Colors.white70,
      borderRadius: BorderRadius.circular(12),
      elevation: 8,
      layout: MenuLayout.horizontal,
    ),
  ),
)
```

### 5.3 添加自定义菜单项

```dart
MarkdownWidget(
  data: markdownData,
  enableCustomSelection: true,
  customSelectionConfig: CustomSelectionConfig(
    extension: MenuExtension(
      items: [
        CustomMenuItem.withContext(
          label: '翻译',
          icon: Icons.translate,
          onContextTap: (context) {
            // 获取元素内容
            final text = context.plainText;
            translateText(text);
          },
        ),
        CustomMenuItem.withContext(
          label: 'AI 摘要',
          icon: Icons.psychology,
          onContextTap: (context) {
            // 获取整个文档
            final markdown = context.fullMarkdown;
            generateSummary(markdown);
          },
        ),
      ],
    ),
  ),
)
```

### 5.4 隐藏内置菜单项

```dart
MarkdownWidget(
  data: markdownData,
  enableCustomSelection: true,
  customSelectionConfig: CustomSelectionConfig(
    hiddenBuiltInItems: {
      BuiltInMenuItem.bookmark,
      BuiltInMenuItem.share,
    },
  ),
)
```

### 5.5 完全自定义菜单

```dart
MarkdownWidget(
  data: markdownData,
  enableCustomSelection: true,
  customSelectionConfig: CustomSelectionConfig(
    extension: MenuExtension(
      position: MenuInsertPosition.replaceAll,
      items: [
        CustomMenuItem.withContext(
          label: '高亮',
          icon: Icons.highlight,
          onContextTap: (context) {
            highlightText(context.index, context.plainText);
          },
        ),
        CustomMenuItem.withContext(
          label: '添加笔记',
          icon: Icons.note_add,
          onContextTap: (context) {
            addNote(context.index, context.plainText);
          },
        ),
      ],
    ),
  ),
)
```

## 七、实现参考

### 7.1 核心架构

```
MarkdownWidget
    ↓
MarkdownGenerator (条件性包裹元素)
    ↓
CustomSelectableWrapper (每个元素)
    ↓
    ├─ AnimatedSwitcher (静态 ↔ 可选模式)
    ├─ GestureDetector (长按检测)
    └─ Overlay (菜单显示)
```

### 7.2 关键技术点

| 技术点 | 方案 |
|--------|------|
| 元素识别 | 为每个元素保留 ElementContext 元数据 |
| 模式切换 | AnimatedSwitcher + Text.rich ↔ SelectableText.rich |
| 菜单显示 | Overlay + OverlayEntry |
| 位置计算 | TextPainter.getBoxesForSelection + RenderBox.localToGlobal |
| 边界处理 | MediaQuery.of(context).size 检测并调整 |
| 手势处理 | GestureDetector with HitTestBehavior.translucent |

### 7.3 文件结构

```

### 8.1 边界情况决策记录

详细的边界情况决策记录请参考：`openspec/changes/custom-selection-mode/BOUNDARY_DECISIONS.md`

**快速参考**：
- **表格**：单元格级选中
- **图片**：不触发选择菜单
- **链接**：选中显示文本，点击仍触发导航
- **嵌套元素**：选中最内层块级元素
- **行内元素**：选中所在段落
- **水平线**：不参与选择

### 8.2 技术设计文档

详细的技术设计请参考：`openspec/changes/custom-selection-mode/design.md`

**关键决策**：
- 元素级包装架构（不是全局替换）
- AnimatedSwitcher 模式转换（平滑过渡）
- Overlay 菜单显示（z-index 正确）
- ElementContext 扩展 API（类型安全）
