# markdown_widget 自定义选择模式需求文档修订版

## 1. 文档说明

本文档基于 `docs/自定义选择模式需求文档.md` 初稿，以及 `openspec/changes/custom-selection-mode/` 下的 `proposal.md`、`design.md`、`specs/markdown-custom-selection/spec.md`、`tasks.md` 整理而成。

本文档用于指导 `MarkdownWidget` 自定义选择模式的设计、实现、测试和验收。Flutter 目标版本为 `3.27.4`。

## 2. 需求背景

当前 `markdown_widget` 通过 `MarkdownWidget(selectable: true)` 支持 Markdown 内容选择与复制，底层依赖 Flutter SDK 的 `SelectionArea`。该能力可以满足基础文本选择，但存在以下限制：

- 长按内容后会立即进入系统选择流程，无法先展示业务自定义菜单。
- 系统选择菜单样式和菜单项扩展能力有限。
- 初始选中范围由 Flutter 文本选择机制决定，无法按 Markdown 语义元素精确控制。
- 图片、分割线、代码块、列表、引用、表格等 Markdown 结构在业务场景中需要更明确的交互边界。

因此需要新增一套可选的自定义选择模式，让业务方能够控制长按菜单、初始选中范围、复制菜单和选区生命周期，同时保持现有默认行为兼容。

## 3. 目标

本次需求目标如下：

- `MarkdownWidget` 支持可选的自定义选择模式。
- 未开启自定义选择模式时，现有 `selectable: true` 行为保持不变。
- 开启自定义选择模式后，用户长按 Markdown 内容时先展示自定义菜单，不立即选中文字。
- 用户点击“选取文字”后，按当前点击位置所属 Markdown 语义元素初始化选区。
- 初始选区出现后，用户仍可拖动选择手柄调整选择范围。
- 支持自定义初始菜单和选中后菜单，并支持业务方扩展 action。
- 支持复制当前选中内容，首版复制渲染后的纯文本。
- 在 `example/` 下提供可运行示例。
- 使用 Flutter `3.27.4` 完成验证。

## 4. 范围与非目标

### 4.1 首版范围

- 仅支持 `MarkdownWidget`。
- 仅保证 Android/iOS 触摸长按交互。
- 支持两阶段菜单：
  - 第一阶段：长按后显示初始自定义菜单。
  - 第二阶段：点击“选取文字”后显示选中区域和选中后菜单。
- 支持标题、段落、列表项、任务列表文本、引用、嵌套引用、代码块、表格单元格、链接文本、行内格式文本的初始语义选区。
- 支持图片、分割线、checkbox 控件等无文本元素不展示“选取文字”。
- 支持滚动、拖动手柄、点击选区内外、点击菜单 action 后的状态管理。

### 4.2 非目标

- 首版不支持 `MarkdownBlock` 自定义选择模式。
- 首版不保证桌面右键、Web 浏览器原生菜单、鼠标拖选等平台特化行为。
- 首版不复制 Markdown 源码、富文本格式或原始 source slice。
- 首版不要求图片、分割线、checkbox 控件成为文本选择目标。
- 首版不要求改变未开启自定义模式时的 `SelectionArea` 默认行为。

## 5. API 与开启方式

`MarkdownWidget` 新增可选配置参数：

```dart
MarkdownWidget(
  data: markdown,
  selectable: true,
  selectionConfig: MarkdownSelectionConfig(
    // 自定义菜单、菜单 action、样式和行为配置
  ),
)
```

行为规则：

- `selectionConfig == null` 时，不开启自定义选择模式，现有 `SelectionArea` 行为保持不变。
- `selectionConfig != null && selectable == true` 时，开启自定义选择模式。
- `selectable == false` 时，禁用所有选择能力。即使传入 `selectionConfig`，也不触发系统选择和自定义选择菜单。

`MarkdownSelectionConfig` 至少需要覆盖以下能力：

- 初始长按菜单 builder。
- 选中后菜单 builder。
- 初始菜单应用自定义 action。
- 选中后菜单应用自定义 action。
- 菜单锚点、当前 Markdown 语义目标、选中文本、关闭菜单、触发选取文字、复制等上下文能力。

初始菜单 builder 默认会收到内置“选取文字” action。业务方允许隐藏、重排或自定义渲染该内置 action。

## 6. 交互流程

### 6.1 默认模式

当 `MarkdownWidget(selectable: true)` 且未传入 `selectionConfig` 时：

- 长按 Markdown 内容区域后的行为保持现有逻辑不变。
- 不出现自定义两阶段菜单。
- 不改变原有选择、复制、滚动和链接点击行为。

当 `selectable: false` 时：

- 不触发系统选择。
- 不触发自定义选择菜单。

### 6.2 自定义选择模式主流程

```text
空闲
  -> 长按可选择文本内容
初始菜单显示，尚未选中文字
  -> 点击“选取文字”
语义块被选中，选择手柄显示，选中后菜单显示
  -> 拖动选择手柄
选区保持，菜单隐藏
  -> 结束拖动
选区保持，选中后菜单重新显示
  -> 页面滚动
选区保持，菜单隐藏，滚动结束后不自动恢复
  -> 点击选区内部
选区保持，选中后菜单重新显示
  -> 点击选区外部或点击菜单 action
清空选区、手柄和菜单，回到空闲
```

### 6.3 初始菜单

开启自定义选择模式后，用户长按 Markdown 内容区域：

- 如果长按位置命中文本型 Markdown 语义目标，展示初始自定义菜单。
- 初始菜单上下文默认包含“选取文字” action 和业务配置的其他 action。
- 初始菜单出现时不得立即创建文本选区，不得显示选中高亮，不得显示选择手柄。
- 如果业务方在 builder 中隐藏“选取文字”，则菜单中不展示该项，也不会由该隐藏项触发选择。
- 如果业务方在 builder 中重排“选取文字”，实际菜单顺序以 builder 输出为准。

无文本元素规则：

- 图片、分割线、checkbox 控件等无文本元素不展示“选取文字”。
- 如果无文本元素存在业务配置 action，可以展示不包含“选取文字”的初始菜单。
- 如果无文本元素没有任何业务 action，则不展示菜单。

### 6.4 点击“选取文字”

用户点击初始菜单中的“选取文字”后：

- 初始菜单关闭。
- 根据长按位置解析 Markdown 语义目标。
- 初始化选中该语义目标对应文本范围。
- 显示选中高亮和选择手柄。
- 显示选中后菜单。

### 6.5 选中后菜单

选中后菜单至少包含复制能力，并允许业务方扩展其他 action，例如收藏、朗读、分享、翻译等。

用户点击复制或任意选中后菜单 action 后：

- 先清空选中后菜单、选区高亮和选择手柄。
- 再执行对应 action。
- 复制 action 将当前调整后的选中文本写入剪贴板。

### 6.6 拖动选择手柄

用户可以拖动选区开始或结束位置的手柄调整范围。

- 拖动开始时，选中后菜单隐藏。
- 拖动过程中，选区高亮和手柄保持。
- 拖动结束后，选中后菜单按调整后的选区重新出现。
- 拖动允许跨 Markdown 块级边界扩展选择范围。

### 6.7 页面滚动

当选区处于激活状态时：

- 用户上下滚动页面，选区逻辑状态必须保留。
- 页面开始滚动时，选中后菜单隐藏。
- 滚动结束后，选中后菜单不自动恢复。
- 选区端点滚出屏幕时，选区不得被清空。
- 端点滚回屏幕后，对应手柄应重新可见。
- 用户点击选区内部后，选中后菜单重新出现。

### 6.8 点击选区内外

当选区处于激活状态时：

- 点击选区内部：保留选区和选择手柄，并显示选中后菜单。
- 点击选区外部：清空选区、选择手柄和菜单。

## 7. Markdown 元素初始选中规则

“初始选中”只发生在用户点击“选取文字”后。之后用户可通过拖动手柄调整实际选区。

| 长按位置 | 初始选中范围 |
| --- | --- |
| `h1` 至 `h6` 标题 | 当前标题完整文本 |
| 普通段落 `p` | 当前段落完整文本 |
| 普通列表项文字 `li` | 当前列表项的直接文本内容，不包含前后列表项，不包含子列表 |
| 嵌套列表项文字 | 当前嵌套列表项的直接文本内容 |
| 任务列表项文字 | 当前任务项的直接文本内容，不包含 checkbox 控件，不包含子列表 |
| 任务列表 checkbox 控件本体 | 不展示“选取文字” |
| 引用块 `blockquote` 内文本 | 最近一层引用块的完整文本，包含该引用块内多个段落 |
| 嵌套引用块内文本 | 最近一层 `blockquote` 的完整文本，不包含外层引用块中不属于该最近引用块的文本 |
| 代码块文本 | 当前代码块完整文本 |
| 代码块原有复制按钮 | 保持按钮原有复制行为，不进入自定义选择流程 |
| 表格单元格文本 | 当前单元格完整文本，后续可拖动手柄调整范围 |
| 链接文本 | 长按优先展示自定义菜单，点击“选取文字”后选中所在块级元素 |
| 链接点击 | 保持现有链接跳转或点击行为，不进入自定义选择流程 |
| 加粗、斜体、删除线、行内代码等行内格式文本 | 选中所在块级语义元素 |
| 图片、分割线等无文本元素 | 不展示“选取文字”；仅在有业务 action 时展示自定义菜单 |

## 8. 复制内容规则

首版复制内容为渲染后的纯文本。

- 复制当前实际选区，而不是初始语义块的固定文本。
- 用户拖动手柄后，复制拖动调整后的范围。
- 代码块复制时保留代码块换行。
- 列表项初始选中只包含当前项直接文本，复制时不包含子列表；如果用户后续拖动包含了子列表，则按实际选区复制。
- 表格单元格初始复制为当前 cell 文本；如果拖动扩展范围，则按实际选区复制。
- 链接默认复制链接显示文本，不额外拼接 URL。
- 不复制 Markdown 源码语法。
- 不复制富文本格式。

## 9. 菜单定位与展示

菜单采用应用侧可控的 overlay 展示方式。

- 初始菜单优先显示在用户长按位置附近。
- 选中后菜单显示在选区附近。
- 菜单锚点需要限制在可见 overlay 范围内，避免靠近屏幕顶部、底部、左右边缘时不可见或溢出。
- 菜单样式由业务方 builder 决定。
- 业务方 builder 返回内容过大时，组件侧提供受限锚点和边界信息，业务方需要在约束内渲染。

## 10. 技术约束

### 10.1 与现有渲染链路的关系

当前 `MarkdownGenerator.buildWidgets()` 会将 Markdown 解析为 `SpanNode` 树后输出 `List<Widget>`，但渲染后的 widget 缺少可反查 Markdown 语义节点的信息。自定义选择模式需要在渲染过程中保留语义选择单元。

语义选择单元至少需要包含：

- Markdown tag 和语义类型。
- 渲染后的纯文本。
- 父级语义信息。
- 文档内稳定 identity。
- 可用于 hit test 或定位的 render key 或等价机制。
- 是否允许展示“选取文字”。
- 可初始化完整选区的边界信息。

该元数据仅需在自定义选择模式开启时启用，避免影响默认渲染路径。

### 10.2 与 Flutter Selection 体系的关系

自定义模式不能只依赖 `SelectionArea.contextMenuBuilder`，因为该 API 无法满足“长按后先显示菜单且不立即选中文字”以及“点击后按 Markdown 语义元素程序化初始化选区”的核心需求。

实现需要使用 Flutter `3.27.4` 公开选择相关能力，例如：

- `SelectionContainer`
- `SelectionContainerDelegate`
- `Selectable`
- `SelectionEvent`

实现不得依赖 Flutter 私有库成员。

### 10.3 选择状态管理

自定义模式需要一个稳定的根选择控制层：

- 负责初始化语义单元选区。
- 负责清空选区。
- 负责判断点击位置是否在当前选区内。
- 负责显示和隐藏选择手柄。
- 负责显示和隐藏选中后菜单。
- 负责读取当前选中的纯文本。
- 负责在 `ListView.builder` 子节点回收、滚动出屏、重新回屏时保留逻辑选区。

## 12. 验收标准

### 12.1 兼容性

- 未传入 `selectionConfig` 时，`MarkdownWidget(selectable: true)` 行为与现有版本一致。
- `selectable: false` 时，不触发系统选择，也不触发自定义菜单。

### 12.2 初始菜单

- 自定义模式下长按段落文本，只显示初始菜单，不立即高亮文本，不显示选择手柄。
- 初始菜单上下文包含“选取文字”和业务 action。
- builder 可以隐藏“选取文字”。
- builder 可以重排“选取文字”。
- 长按链接文本优先展示自定义菜单。
- 长按图片、分割线、checkbox 控件等无文本元素时不展示“选取文字”。
- 无文本元素没有业务 action 时不展示菜单。

### 12.3 初始选区

- 长按标题并点击“选取文字”后，选中当前标题全文。
- 长按段落并点击“选取文字”后，选中当前段落全文。
- 长按列表第三项并点击“选取文字”后，只选中第三项直接文本。
- 长按任务列表项文本并点击“选取文字”后，不选中 checkbox 控件和子列表。
- 长按多段引用内任意段落并点击“选取文字”后，选中最近引用块全文。
- 嵌套引用中点击内层引用文本时，只选中最近一层引用。
- 长按代码块文本并点击“选取文字”后，选中整个代码块。
- 长按表格单元格文本并点击“选取文字”后，选中当前 cell。
- 长按链接、加粗、斜体、行内代码等行内文本并点击“选取文字”后，选中所在块级元素。

### 12.4 交互状态

- 拖动选择手柄时，选中后菜单隐藏，选区和手柄保留。
- 拖动结束后，选中后菜单重新出现。
- 页面滚动时，选中后菜单隐藏，选区保留。
- 页面滚动结束后，菜单不自动恢复。
- 选区滚出屏幕后再滚回，选区和手柄仍然存在。
- 点击选区内部，选区和手柄保留，菜单出现。
- 点击选区外部，选区、手柄和菜单全部清空。
- 点击复制或其他菜单 action 后，选区、手柄和菜单全部清空。

### 12.5 复制

- 点击复制后，剪贴板内容为当前实际选区的渲染纯文本。
- 代码块复制保留换行。
- 拖动调整后复制的是调整后的范围。

### 12.6 现有交互保留

- 点击链接仍执行现有链接点击行为，不进入自定义选择流程。
- 代码块原有复制按钮继续保留原行为，点击它不进入自定义选择流程。
- 未开启自定义模式时，所有现有选择行为保持不变。

### 12.7 验证

- 使用 Flutter `3.27.4` 执行格式化、静态分析和测试。
- 覆盖默认路径、自定义路径、语义初始选区、菜单生命周期、滚动保留、跨块拖动、复制和示例验证。
- 手动验证 Android 和 iOS 触摸长按流程。

## 13. 后续增强方向

以下能力不属于首版范围，可后续单独立项：

- `MarkdownBlock` 自定义选择模式。
- 桌面右键菜单、双击选词、鼠标拖选。
- Web 浏览器原生菜单适配。
- Markdown 源码复制。
- 富文本复制。
- 链接复制时附带 URL 的格式选项。
- 更细粒度表格选择，例如行、列、整表。
- 高亮颜色、触觉反馈、无障碍 Semantics 等增强配置。
