# markdown_widget 自定义选择模式需求文档（修订版）

> **文档版本**：v2.0
> **基础版本**：自定义选择模式需求文档 v1.0
> **Flutter 版本要求**：3.27.4（Dart SDK 3.6.2）
> **适用组件**：`MarkdownWidget`（ListView 模式）、`MarkdownBlock`（Column 模式）

---

## 1. 需求背景

### 1.1 现状

当前 `markdown_widget` 通过 `selectable` 参数（默认 `true`）开启文本选择和复制能力，底层基于 Flutter SDK 的 `SelectionArea` 实现。

### 1.2 现有局限

| 局限 | 说明 |
|---|---|
| **菜单不可定制** | 长按弹出的功能菜单（剪切/复制/全选）样式和内容完全由系统控制，无法自定义 UI 或扩展功能项 |
| **选中粒度受限** | 默认行为是长按后选中一个词，用户无法按 Markdown 语义结构（标题、段落、列表项等）进行智能初始选中 |
| **无元素信息暴露** | 使用者无法获知用户长按/选中的具体 Markdown 元素类型、原始源码等上下文信息 |
| **编程式选择不可达** | Flutter `SelectableRegionState` 的核心方法（`_selectStartTo`、`_selectEndTo`、`_selectable`）均为私有，无法从外部进行编程式选择 |

### 1.3 目标场景

- AI 问答平台——需要长按引用某段回答、复制原始 Markdown 源码
- 笔记/阅读类应用——需要按段落/标题粒度选取内容，配合收藏、翻译、分享等自定义操作
- 内容编辑工具——需要精细的块级元素选择与操作

---

## 2. 需求概述

新增**自定义选择模式**，支持两阶段交互：

1. **阶段 1（长按阶段）**：用户长按 Markdown 内容区域，**暂不选中文字**，在长按位置弹出自定义功能菜单，暴露当前元素的完整信息和坐标
2. **阶段 2（选取文字阶段）**：用户点击菜单中的"选取文字"后，**自动选中当前长按位置对应的 Markdown 块级元素的全部文字**，弹出第二阶段自定义菜单（如复制、收藏、翻译），支持拖动选择手柄调整选区范围

### 2.1 前提条件

- `selectable = true`（默认值）
- `MarkdownConfig` 中传入了 `customSelectionConfig` 配置

如果 `selectable = false`，即使配置了 `customSelectionConfig` 也不会激活自定义选择模式。
如果 `selectable = true` 但未配置 `customSelectionConfig`，保持现有原生 `SelectionArea` 行为不变。

### 2.2 支持组件

| 组件 | 布局模式 | 支持 |
|---|---|---|
| `MarkdownWidget` | ListView（可滚动） | ✅ |
| `MarkdownBlock` | Column（自适应高度） | ✅ |

### 2.3 平台范围

第一版仅支持**移动端**（Android / iOS），桌面端和 Web 端后续迭代。

## 3. 交互规格

### 3.1 交互状态机

```
空闲状态
  │
  ├── 长按可选元素 ──→ 阶段 1（自定义菜单弹出）
  │                       │
  │          ┌─────────────┼──────────────┐
  │          │             │              │
  │     点击空白区域    点击功能按钮    点击"选取文字"
  │       ↓              ↓               ↓
  │     空闲状态    执行回调→空闲    阶段 2（选中+菜单弹出）
  │                                      │
  │              ┌───────────────┬────────┼────────┐
  │              │               │        │        │
  │         拖动手柄        点击选中内部  点击外部  点击菜单按钮
  │           ↓               ↓          ↓        ↓
  │      菜单消失→         菜单重现    全部消失  执行回调→
  │      拖动结束→菜单重现              →空闲     全部消失→空闲
  │
  └── 长按图片/水平线 ──→ 不响应（忽略）
  │
  └── 已有选区时再次长按 ──→ 清除旧选区 → 弹出新阶段1菜单
```

### 3.2 阶段 1 详细交互

| 步骤 | 行为 |
|---|---|
| 1. 用户长按 | 检测长按位置对应的 Markdown 块级元素，**不选中文字** |
| 2. 触觉反馈 | 如果 `hapticFeedback = true`（默认），触发设备振动 |
| 3. 弹出菜单 | 在长按位置弹出阶段 1 自定义菜单，传入元素信息、长按坐标、"选取文字"回调 |
| 4. 点击空白 | 菜单消失，回到空闲状态 |
| 5. 点击按钮 | 执行按钮回调 → 菜单消失 → 回到空闲 |
| 6. 点击"选取文字" | 进入阶段 2 |

### 3.3 阶段 2 详细交互

| 步骤 | 行为 |
|---|---|
| 1. 自动选中 | 阶段 1 菜单消失，对应元素全部文字被选中高亮，显示拖动手柄 |
| 2. 弹出菜单 | 在选区上方弹出阶段 2 自定义菜单，传入选中文本、位置坐标、关闭回调 |
| 3. 拖动手柄 | 菜单消失，用户拖动手柄调整选区范围（可跨元素），拖动结束后菜单重新出现 |
| 4. 点击选中内部 | 如果菜单已消失，重新显示菜单；选区和手柄保持不变 |
| 5. 点击选中外部 | 选区高亮、手柄、菜单全部消失，回到空闲状态 |
| 6. 点击菜单按钮 | 执行按钮回调 → 选区高亮、手柄、菜单全部消失 → 回到空闲 |
| 7. 页面滚动 | 选区和手柄保持不变，滚动回来后仍然可见 |
| 8. 跨元素选择 | 拖动手柄可跨越多个元素，扩展选区范围 |

## 4. 元素选中粒度

用户长按后点击"选取文字"，系统按以下规则确定初始选中范围：

| Markdown 元素 | 选中范围 | 长按是否响应 | 备注 |
|---|---|---|---|
| 标题 h1-h6 | 整个标题文字 | ✅ | |
| 段落 p | 当前段落全部文字 | ✅ | |
| 列表项 li | 当前条目的文字 | ✅ | 不含嵌套子列表的内容 |
| 引用 blockquote | 被命中的最小段落 | ✅ | 嵌套引用取最内层命中的段落 |
| 代码块 pre | 整个代码块文字 | ✅ | 保留缩进和换行 |
| 表格 table | 整个表格内容 | ✅ | 第一版整表选中，后续优化为单元格 |
| 图片 img | — | ❌ | 长按不触发菜单 |
| 水平线 hr | — | ❌ | 长按不触发菜单 |
| 链接 a | 遵从所在父元素 | ✅ | 按父元素（如段落）选中 |
| 行内代码 code | 遵从所在段落 | ✅ | 按父段落选中 |
| 复选框 input | 同所在列表项 | ✅ | 视为列表项处理 |
| 加粗/斜体/删除线 | 遵从所在父元素 | ✅ | 行内元素不独立选中 |

### 4.1 嵌套场景

- **嵌套列表**：长按子项时，只选中该子项的文字，不包含其父级或同级条目
- **引用内嵌套**：引用块内有多个段落时，选中被命中的那个段落，而非整个引用块
- **引用内列表**：长按引用块内的列表项，选中该列表项
- **空内容元素**：长按空段落/空列表项不弹出菜单
- **Padding/间隙**：长按两个元素之间的 padding 区域，归入最近的块级元素

## 5. API 设计

### 5.1 配置入口

通过 `MarkdownConfig` 构造函数的 `customSelectionConfig` 命名参数开启：

```dart
MarkdownWidget(
  data: markdownString,
  selectable: true,  // 必须为 true
  config: MarkdownConfig(
    customSelectionConfig: CustomSelectionConfig(
      firstStageMenuBuilder: (context, elementInfo, globalPosition, onSelectText) {
        // 返回阶段 1 自定义菜单 Widget
      },
      secondStageMenuBuilder: (context, selectedText, globalPosition, onDismiss) {
        // 返回阶段 2 自定义菜单 Widget
      },
      onTextSelected: (text) {
        // 选中文本变化时的回调
      },
    ),
  ),
);
```

`MarkdownBlock` 使用方式完全相同。

### 5.2 CustomSelectionConfig

```dart
class CustomSelectionConfig {
  /// 阶段 1 菜单构建器（长按时弹出）
  /// 必需参数，library 不提供默认菜单，使用者完全控制菜单 UI 和行为
  ///
  /// 参数说明：
  /// - context: BuildContext
  /// - elementInfo: 长按位置对应的元素信息（类型、文本、坐标等）
  /// - globalPosition: 长按的全局屏幕坐标
  /// - onSelectText: 调用后进入阶段 2（选取文字）
  final Widget Function(
    BuildContext context,
    MarkdownElementInfo elementInfo,
    Offset globalPosition,
    VoidCallback onSelectText,
  ) firstStageMenuBuilder;

  /// 阶段 2 菜单构建器（选中文字后弹出）
  /// 必需参数
  ///
  /// 参数说明：
  /// - context: BuildContext
  /// - selectedText: 当前选中的纯文本
  /// - globalPosition: 选区中心的全局屏幕坐标
  /// - onDismiss: 调用后关闭菜单并清除选区
  final Widget Function(
    BuildContext context,
    String selectedText,
    Offset globalPosition,
    VoidCallback onDismiss,
  ) secondStageMenuBuilder;

  /// 选中文本变化时的回调（可选）
  /// 在阶段 2 初始选中和用户拖动手柄调整选区后触发
  final void Function(String selectedText)? onTextSelected;

  /// 选中高亮颜色（可选，默认使用系统主题色）
  final Color? selectionColor;

  /// 长按时是否触发触觉反馈（默认 true）
  final bool hapticFeedback;
}
```

### 5.3 MarkdownElementInfo

```dart
class MarkdownElementInfo {
  /// 元素类型（h1, h2, ..., p, li, pre, blockquote, table, etc.）
  final MarkdownTag tag;

  /// 渲染后的纯文本（去除 markdown 语法标记）
  /// 例如 "**bold** text" → "bold text"
  final String plainText;

  /// 原始 Markdown 源码（保留语法标记）
  /// 例如 "# Title" 完整保留，代码块包含围栏标记
  final String sourceText;

  /// 在生成的 Widget 列表中的索引（零基）
  final int widgetIndex;

  /// 元素在屏幕上的全局坐标范围（可能为 null）
  final Rect? globalRect;
}
```

## 6. 边界规则

| 边界场景 | 行为 |
|---|---|
| `selectable=false` + `customSelectionConfig` 非 null | 不激活自定义选择模式，`selectable=false` 优先 |
| `selectable=true` + `customSelectionConfig` 为 null | 使用标准 `SelectionArea` 行为（完全向后兼容） |
| 嵌套列表长按子项 | 只选当前子项文字，不含父级或子列表 |
| 引用块内嵌套多段落 | 选中被命中的最小段落 |
| 复选框长按 | 视为列表项，弹出选择菜单 |
| 已有选区时再次长按 | 清除旧选区，弹出新的阶段 1 菜单 |
| TOC 跳转 | 自动清除现有选区 |
| 点击元素 padding 间隙 | 归入最近的块级元素 |
| 空内容元素 | 不弹出菜单 |
| 代码块复制 | 保留缩进和换行 |
| 跨元素拖动后复制 | 按顺序拼接纯文本 |
| 长按延迟 | 使用系统默认值（~500ms） |

## 7. 技术方案要点

### 7.1 核心组件：CustomSelectableRegion

基于 Flutter 3.27.4 的 `SelectableRegion` 源码最小化改造，创建 `CustomSelectableRegion`：

| 能力 | 原版 SelectableRegion | CustomSelectableRegion |
|---|---|---|
| 长按行为 | 选中一个词 + 显示系统菜单 | 回调外部，不选中 |
| 编程式选择 | 不支持 | `selectRange(start, end)` |
| Handle 控制 | 内部管理 | `showHandles()` / `hideHandles()` |
| 获取选中文本 | 不公开 | `getSelectedContent()` |
| 上下文菜单 | 系统默认 | 禁用，由外部 Overlay 控制 |
| Handle 拖动回调 | 无 | `onHandleDragStart` / `onHandleDragEnd` |
| 选区高亮/Handle 渲染 | ✅ 保留 | ✅ 保留 |
| 跨 Widget 选择 | ✅ 保留 | ✅ 保留 |
| 滚动保持 | ✅ 保留 | ✅ 保留 |

### 7.2 手势架构

所有手势统一由 `CustomSelectableRegion` 处理，避免多层 `GestureDetector` 冲突：
- 长按时通过 hit-test 反查命中的 Markdown 元素
- 元素元数据通过 `InheritedWidget` 附加到每个块级 Widget 上
- 无需在每个元素外额外包裹 `GestureDetector`

### 7.3 sourceText 提取

`markdown` 7.1.1 包的 AST 节点不保留源码行号，`textContent` 仅返回纯文本。通过**行号匹配法**提取原始源码：
1. 解析前保留原始行列表
2. 利用顶层 AST 节点与原始行的顺序对应关系推算行号区间
3. 从原始行中截取对应区间作为 `sourceText`

### 7.4 Overlay 管理

菜单的 Overlay 生命周期封装在 `CustomSelectableRegion` 内部（StatefulWidget），统一管理：
- 阶段 1/阶段 2 菜单的创建、显示、更新、销毁
- 状态机转换（空闲 → 阶段 1 → 阶段 2 → 空闲）
- Widget dispose 时自动清理 OverlayEntry

## 10. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| Flutter SDK 升级导致 `SelectableRegion` 源码变化 | `CustomSelectableRegion` 可能不兼容 | 保持最小化修改；升级时 diff 检查 |
| `sourceText` 行号匹配在复杂嵌套场景偏移 | 源码截取不准确 | 回归测试覆盖；提供 plainText 作为 fallback |
| 手势 hit-test 性能 | 元素很多时遍历开销 | ListView 只渲染可见项；Markdown 文档元素数通常有限 |

## 13. 使用示例

### 13.1 最简使用

```dart
MarkdownWidget(
  data: '# Hello\n\nThis is a paragraph.',
  config: MarkdownConfig(
    customSelectionConfig: CustomSelectionConfig(
      firstStageMenuBuilder: (ctx, info, pos, onSelect) {
        return _buildFirstMenu(info, pos, onSelect);
      },
      secondStageMenuBuilder: (ctx, text, pos, onDismiss) {
        return _buildSecondMenu(text, pos, onDismiss);
      },
    ),
  ),
);
```

### 13.2 Example App 演示页面

在 example app 侧边栏新增 **"Custom Selection"** 页面，包含覆盖以下 Markdown 场景的测试内容：

- 多级标题（h1 ~ h3）
- 普通段落（含加粗、斜体、行内代码、链接）
- 水平线
- 无序列表（含嵌套子列表）
- 有序列表
- 引用块（含嵌套引用、引用内列表）
- 代码块（含语言标记）
- 表格
- 图片
- 复选框（已完成/未完成）
- 多个连续独立段落

菜单 UI 示例：
- **阶段 1 菜单**：竖向列表，包含"选取文字"、"复制原文"、"收藏"、"分享"
- **阶段 2 菜单**：横向工具栏，包含"复制"、"收藏"、"翻译"
- **调试面板**：页面底部显示当前操作的元素类型、纯文本、源码
